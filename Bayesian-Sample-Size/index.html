核心公式清單：

  • • 修正因子: $R_{prior} = \min(0.995, R_{input} \times DCC \times RAM)$
  • • 期望值 (PERT): $E(R) = (L_{prior} + 4M_{prior} + H_{prior}) / 6$
  • • 變異數 (PERT): $Var(R) = ((H_{prior} - L_{prior}) / 6)^2$
  • • Beta 參數: $common = [E(R) - E(R)^2] / Var(R) - 1$
  • • 擬合參數: $a = (1 - E(R)) \times common$, $b = E(R) \times common$
  • • 貝氏求解: $Confidence = \text{Beta.DIST}(1-R_{target}, a+f, b+n-f, \text{TRUE})$
