# 備援系統可靠度評估工具 (Redundancy Reliability) - 使用者操作標準指導書 (SOP)

## 1. 工具目的
本工具旨在協助硬體設計與可靠度工程師，快速評估不同備援架構（串聯、並聯、冷/溫備用、負載分擔等）對系統可靠度與壽命的影響。透過輸入基礎元件的失效參數，工具能以嚴謹的馬可夫模型與數值積分，即時繪製出各架構的可靠度衰退曲線。

## 2. 核心參數與資料來源指南

確保分析準確性的關鍵在於輸入正確的失效參數。以下為各項參數的建議獲取途徑與考量方法：

### 2.1 主元件失效率 (λ)
主元件在「100% 全載 / 目標運作狀態」下的失效率。建議依序由以下三種途徑獲取：

1. **過往退貨維修數據 (Historical RMA Rate)**：
   * 根據市場實際運作表現推算，通常最貼近真實應用環境。
   * **⚠️ 實務注意事項**：若目標評估對象是組裝在模組 (Module) 內部的單一零件，且售後維修行為是「直接更換整個模組」而無法精確追溯至該零件失效時，此 RMA Rate 代表的是「模組級的失效率」。因此，在評估「模組上的單一零件備援」時，其零件失效率就**不能**直接參考該 RMA 資料。
2. **可靠度測試資料 (Reliability Test Data)**：
   * 根據供應商提供的可靠度測試報告（如 HTOL 高溫壽命測試），或內部自行執行的加速壽命測試 (ALT) 推算而得。
3. **一般零件可靠度手冊 (Reliability Handbooks)**：
   * 參考如 Telcordia SR-332, MIL-HDBK-217 等業界標準。適用於設計初期，尚無實際測試數據時的基準預估。

### 2.2 降載失效率 (λ_half) 與 溫備用失效率 (λ_stby)
當元件處於「負載分擔 (Load-Sharing)」或「溫/熱備用 (Warm/Hot Standby)」狀態時，因應力降低而改善的失效率。

* **轉換方法**：
  建議基於「主元件失效率 (λ)」，搭配熱傳實驗量測到的「主元件運作溫度 (T_active)」與「降載/備用狀態量測溫度 (T_stby)」，再套用 **IEC 61709** 標準中對應元件的「溫度加速因子 (π_T)」模型，精準換算出新的失效率。避免無依據的猜測。

### 2.3 韋伯分佈的形狀參數 (Weibull β value)
若元件存在明顯的「老化/磨耗」特性（如風扇、電解電容），應使用 Weibull 分佈。β 值決定了老化惡化的速度。

1. **可靠度測試資料 (Empirical Test Data)**：
   * 根據廠商提供的失效數據分佈，或內部實際執行破壞性測試後，透過 Weibull 分析擬合 (Curve Fitting) 求得真實的 β 值。
2. **學術與業界文獻 (Literature)**：
   * 針對該零件在特定使用條件下的「預期失效機制 (Failure Mechanism)」，尋找相關文獻或經驗法則推薦的 β 值。
   * *註：若完全無老化資料可參考，退回使用「指數分佈 (Exponential, 恆定失效率)」通常是實務上較為標準的假設。*

### 2.4 切換任務成功機率 (P_sw)
備用系統在偵測到主元件失效時，成功切換至備用元件的機率。
* 通常由偵測電路 (Detection) 與切換開關 (Switch) 的可靠度決定。若為理想設計可設為 1，但實務上建議評估偵測機制可能存在的盲區或硬體故障率，設定為 0.95 ~ 0.99 等符合真實物理限制的值。

## 3. 系統架構解析與判讀

* **Pure Parallel (純並聯)**：兩顆元件從頭到尾皆以 100% 全載 (λ) 運作，屬較保守的並聯預估。
* **Load-Sharing (負載分擔)**：兩顆元件平分負載，前期享受低溫降載紅利 (λ_half)。當一顆失效時，剩餘元件需瞬間扛起全載（應力突增回 λ）。只要降載能有效降溫，其整體可靠度表現通常為所有架構中最佳。
* **Cold Standby (冷備用)**：備用件完全斷電 (λ_stby = 0)，壽命消耗最少，但需承擔啟動延遲與切換失敗 (P_sw < 1) 的風險。
* **Warm Standby (溫備用)**：備用件維持部分供電或怠速 (λ_stby > 0)，有部分壽命消耗，但能極快接管。
